## 🚀 Sobre mim

Sou estudante de Engenharia de Software apaixonado por desenvolvimento web, interfaces responsivas e criação de soluções práticas com tecnologia. Tenho me dedicado ao estudo de HTML, CSS, JavaScript, banco de dados e Git/GitHub, buscando evoluir por meio de projetos reais e bem estruturados.

Meu objetivo é desenvolver habilidades sólidas em front-end, lógica de programação e organização de projetos, ampliando minha base técnica para atuar com mais segurança no mercado de tecnologia.
